All Looking Eye
About the Project
All Looking Eye is a real-time, multi-modal anomaly and violence detection system. It analyzes live or recorded video feeds to identify abnormal human behavior using deep learning and pose estimation.

The core of the system is driven by an Anomaly Fingerprint Engine that processes sequences of body movements to detect threats with high accuracy. When a critical anomaly is detected, the system automatically isolates a video clip of the event and dispatches an email alert to administrators.
